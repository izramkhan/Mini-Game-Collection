# 🎮 Mini-Game-Collection

A Python-based collection of five fun mini-games playable directly in your terminal.

---

## 📋 Description

**Mini-Game-Collection** is an interactive command-line program that bundles five classic mini-games into one place. Each game comes with its own rules explained at the start. Simply pick a game and start playing — enter `0` at any time to exit the program.

---

## 🕹️ Games

| # | Game |
|---|------|
| 1 | 🧠 **Mini Quiz** |
| 2 | 🔢 **Guess the Number** |
| 3 | 🌍 **Guess the Country** |
| 4 | ✊ **Rock Paper Scissors** |
| 5 | 🎲 **Dice Battle** |

> Each game explains its own rules at the beginning of the session.

---

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your machine

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/izramkhan/Mini-Game-Collection.git
   ```
2. Navigate into the project directory:
   ```bash
   cd Mini-Game-Collection
   ```

### Running the Program

```bash
python main.py
```

---

## 🎯 How to Play

1. Launch the program.
2. You will be greeted with the main menu listing all five games.
3. Enter the number corresponding to the game you want to play.
4. Read the rules displayed at the start of each game and play away!
5. Enter `0` at any time to exit the program.
